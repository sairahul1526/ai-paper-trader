PAPER CONTROL PLANE

Configure and run

Paper only · no live orders
US setup 1. Create a free Alpaca paper account and copy its paper API key and secret. 2. Enter a US venue and ticker (for example NASDAQ / AAPL). 3. Enter the TypeSafe key and save credentials. 4. Click Run paper loop. Free real-time coverage is IEX; historical bars use Alpaca’s IEX feed.
Market & run

The provider supplies observations only. Every action is simulated locally in the paper ledger.

History & AI request

State includes the current quote, order-book fields when available, the current candle, history, session, position, account, and these config values. One request is made per completed 1-minute candle.

Local risk rules

Risk checks are the only local action gate. There are no hard-coded entry patterns.

Provider and TypeSafe credentials never printed in full

US mode uses Alpaca's paper/basic market-data credentials. The free feed is real-time IEX coverage and historical bars; it is not the full consolidated tape. Create a paper account at alpaca.markets, then paste the paper API key and secret.

Not saved in this browser

Save stores values in this browser's local storage only. Do not use this option on a shared computer. The server receives credentials only when starting a local paper run.

Provider receipt diagnostics appear after a run starts.
